# 甘文杰 · 奖学金申报自我介绍

这是一个本地可直接打开的单页作品集，按「LEARNING → BUILDING → RESEARCHING」展开学业基础、MentalFlow 项目与持续学习方向。

## 打开页面

用浏览器打开项目根目录中的 `index.html` 即可。页面不需要安装依赖或启动服务；论文学习区直接引用 `assets/` 中的原始截图。

## 页面内容

- 学业基础：GPA、核心课程、知识结构和两项竞赛经历。
- MentalFlow：通过步骤切换查看日程、对话证据、建模链路、个体差异、风险延迟与反馈闭环。
- Continual Learning：交互式概念演示，以及 EWC、LwF、iCaRL 的真实页面截图。
- 收束：以「适应变化，也适应不同的人」连接持续学习与个性化。

MentalFlow 曲线与持续学习探针均为概念示意，不代表测量数据、正式算法结果或论文实验结果。
